# Structure

- `src/`: all application or library code. Tests live next to the file they test.
- `vite.config.ts`: build, dev server and test projects.
- `.kiro/`: steering (these files), agents and MCP settings for AI assistants.
- Import project files with the `@/` alias (`@/components/Button`) rather than long relative paths.
